# Design

**Discord-style structure, Apple-style look.**

## Structure (like Discord)

- Communities, each with text channels and voice Spaces.
- A list of communities on one side, channels inside each.
- Direct messages and "someone to talk to" sit alongside communities.

## Look and feel (like Apple and iMessage)

Tero follows Apple's Human Interface Guidelines, on iOS, Android and web
alike.

| Area | Style |
|---|---|
| Chats | iMessage-style bubbles, tapbacks (reactions), typing indicator, swipe to reply |
| Navigation | Tab bar at the bottom, large titles, sheets that slide up |
| Lists | Grouped, inset lists like iOS Settings |
| Motion | Soft, quick spring animations; reduced when the phone asks for less motion |
| Colour | Light and dark mode, with the tarot theme as an accent colour, not decoration everywhere |
| Text | Dynamic Type, so text follows the phone's size setting |
| Accessibility | VoiceOver and TalkBack labels, enough contrast, large tap targets |

## Fonts

Apple's San Francisco font may only be used on Apple devices.

- **iOS:** the system font (San Francisco).
- **Android and web:** Inter, which looks very similar and is free to use.
- **Chinese:** the system's Chinese font on each platform.

## The tarot theme

- Cards appear where they mean something: council seats, Tero card
  invites, recovery and Sequences.
- Card art is Tero's own, not from the novel.
- Everyday screens stay clean and calm.
